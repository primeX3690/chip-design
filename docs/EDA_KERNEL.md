# EvoHDL EDA kernel (`evohdl/eda/`) -- a tool-independent logic-level flow

Pure Python, no external binaries. `python -m evohdl.eda <command>`:

| command | what it does |
|---|---|
| `elab FILE.v --top M [--out x.aag]` | Verilog subset -> AIG (hierarchy flattened, parameters, always/if/case, registers) |
| `opt FILE` | cut-based rewrite + balance + SAT sweeping, then **proves** the result equivalent |
| `map FILE --lib libs/tiny_generic.lib` | technology mapping (cut matching, area or delay objective), structural Verilog out |
| `sta FILE --sdc c.sdc` | static timing (NLDM tables, rise/fall, setup) + switching-activity power |
| `cec A B` | equivalence of two designs (`.v .sv .aag .bench`): SAT miter, latch-matched, bounded BMC |
| `flow FILE` | optimize -> verify -> map -> verify -> STA -> power, one report |
| `bench list / run [name\|all] / run-dir DIR` | benchmark circuits; `run-dir` takes real ISCAS/EPFL `.bench`/`.aag` files |
| `regress` | run every benchmark, store in `benchmarks/eda_regression.db`, exit 1 on any regression |

## How this maps to the "missing for a real EDA tool" list

| Item | Status |
|---|---|
| HDL front-end (parser, AST, elaboration) | Parser/AST/printer (`evohdl/hdl/`) + **elaborator to AIG** (`elaborate.py`). Verilog-2001 + SV subset; no `generate`, functions, loops, signed math, VHDL |
| Netlist IR (cells, nets, hierarchy) | `netlist.py` (library-cell instances, DFFs, aliases, simulation, back-conversion to AIG, Verilog writer). Hierarchy is flattened at elaboration (names keep an instance prefix) |
| Logic optimization + tech mapping + liberty | AIG with structural hashing + 2-level simplification, `rewrite`, `balance`, `fraig`; cut-based mapper; Liberty parser (NLDM) |
| STA + SDC | `sta.py`: setup analysis, single ideal clock, SDC subset |
| Own simulator / coverage / formal without Yosys | AIG bit-parallel simulator, `pysim` for RTL, own CDCL SAT solver, CEC, latch-matched sequential check, BMC. **Coverage metrics: not done** |
| Bigger benchmarks, regression DB, CLI | c17 (exact) + 16 generated/RTL circuits, SQLite regression DB, CLI. **Real ISCAS-85/EPFL/OpenCores suites are not bundled** (no network here): drop files in a folder and use `bench run-dir` |
| Placement / routing / LEF / DEF / GDSII | **Deliberately not built.** Without a real PDK's rules and cell geometry these would be toy placers that give false confidence; use OpenLane/OpenROAD (a wrapper already exists in `evohdl/self_improve_loop/openlane_runner.py`) |
| Physical DRC / LVS | **Not built**, same reason. (Only the *logical* equivalence of a netlist vs its source, which `cec` does, is covered) |
| Power analysis | Statistical dynamic + leakage estimate only (`estimate_power`); not signoff |

## Honest limits you should know before relying on it

- **The library is fictional.** `libs/tiny_generic.lib` (14 cells) is generated by `scripts/make_tiny_lib.py` with made-up
  numbers so the real Liberty/NLDM code path runs. Area/delay/power numbers are NOT comparable to any silicon process.
  Point `--lib` at a real `.lib` (supported subset: see `liberty.py` docstring) to get meaningful numbers.
- **SAT solver is teaching-grade.** Pure Python. Small/medium cones are fine; multiplier-style equivalence of differently
  structured netlists is hard for it (`mult6` mapped-netlist check exceeds the conflict budget, so the flow reports
  `SIM_ONLY` -- random simulation, explicitly *not* a proof). Raise `--conflicts` for a real attempt.
- **Optimization strength is modest.** On the shipped benchmarks it removed 0-80% of AND nodes (redundant logic: 70->14;
  alu_basic 313->248; plain adders/multipliers: 0%). `balance` handles AND trees only, so a linear XOR chain
  (`parity16`) keeps its depth. It is not competitive with ABC; its value is that it is yours, verified, and dependency-free.
- **Sequential model:** single implicit clock, reset sampled at the edge, registers start at 0, equivalence from reset is
  proven only when register names match (else bounded BMC).
- **STA** is setup-only on an ideal clock with flat wire cap; no hold, no skew, no multi-clock, no derating.
- **Elaborator validation:** fuzzed against `pysim` on thousands of random expressions plus all seed designs and
  hierarchical/parameterised examples; `pysim` itself was checked against the project's golden models. Both are *this
  repo's* semantics of Verilog, not an independent reference simulator.
